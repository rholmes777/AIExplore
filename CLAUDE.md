# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

AIExplore is a comprehensive knowledge management repository focused on AI tools, methodologies, and development workflows. This is primarily a documentation and research repository rather than a traditional codebase, containing guides, cheat sheets, and best practices for AI-assisted development.

## Repository Structure

### Key Directories
- `AI on AI/` - Research on AI models analyzing themselves
- `AI Sentience Debate/` - Philosophical discussions and research
- `Aider/` - Documentation for the Aider CLI tool
- `APIs and MCPs/` - API integrations and Model Context Protocol documentation
- `Application Ideas/` - Project concepts and planning documents
- `Dev Cheat Sheets and Tutorials/` - Quick reference guides for development tools
- `Models and Useage/` - Comprehensive guides for Claude, ChatGPT, Copilot, and other AI tools
- `Productivity/` - Workflow optimization strategies
- `Software Prompting/` - Prompt engineering techniques and patterns
- `Image Prompts/` - AI image generation guides

## Development Context

### Repository Type
This is a documentation repository without traditional build processes or test suites. The primary workflow involves:
- Creating and updating Markdown documentation
- Organizing research and notes
- Documenting AI tool usage patterns and best practices

### Version Control
- Main branch: `master`
- Use standard git workflow for documentation updates
- Focus on clear, descriptive commit messages for documentation changes

## Working with This Repository

### When Adding Documentation
1. Follow the existing hierarchical organization structure
2. Use Markdown for all documentation files
3. Place content in the most appropriate existing directory
4. Cross-reference related topics when relevant

### When Researching AI Tools
1. Check existing documentation in `Models and Useage/` before creating new files
2. Update existing guides rather than creating duplicates
3. Include practical examples and use cases

### When Documenting Workflows
1. Place workflow documentation in `Productivity/` or relevant tool-specific directories
2. Include step-by-step instructions where appropriate
3. Reference specific tools and their configurations

## Key Areas of Focus

### Agentic Workflows
The repository contains extensive documentation on agent-based development patterns in `Models and Useage/Agentic Workflows and Tools/`. When working with agent-related content, maintain consistency with existing patterns and terminology.

### Prompt Engineering
`Software Prompting/` contains systematic approaches to AI interaction. New prompt strategies should be documented with examples and use cases.

### Development Tool Integration
Documentation for various AI coding assistants (Claude Code, Copilot, Cursor) is maintained in respective directories. Keep tool-specific documentation separate and well-organized.

## Important Notes

- This is a knowledge repository, not an executable codebase
- No build, test, or deployment commands are needed
- Focus on documentation quality and organization
- Maintain the existing structure when adding new content
- Avoid creating redundant documentation - update existing files when possible
