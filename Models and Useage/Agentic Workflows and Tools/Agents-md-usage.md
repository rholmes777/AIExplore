### How to Use
1. **Add** this `Agents.md` to a repository.  
2. **Fill** template variables *or* provide an `agent-config.yaml` with the same keys.  
3. **Run** your agent manager (Codex, Claude, etc.).  
4. **Iterate**: As agents produce docs, refine config values or prompt them for deeper analysis.

This template keeps guidance concise yet complete, ensuring agents focus on **discovering architecture, design intent, and clear documentation** without being biased toward any single stack or pattern.
