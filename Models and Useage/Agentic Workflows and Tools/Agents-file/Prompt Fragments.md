  - `## Overview`

  - `## Dependencies`

## **2 ▪ Prompt Library for Documentation Workflow**

  

Paste prompts as needed; each builds on the previous step.

|**Stage**|**Prompt**|
|---|---|
|**A. Outline**|**“Analyze the repository structure (read‑only) and propose a documentation plan following the files specified in Agents.md. Produce a bulleted outline listing which sections will appear in each file. Only outline – do not write content yet.”**|
|**B. Review / Approve**|_(Human action)_ – skim the outline, add or remove bullets, then reply: **“Approved outline (with edits). Proceed.”**|
|**C. Draft per File**|**“Create the complete ARCHITECTURE.md file as per the approved outline. Follow the Documentation Standards in Agents.md. When diagrams are needed, embed Mermaid code.”**_(Repeat for each planned file.)_|
|**D. Cross‑Check**|**“Cross‑check ARCHITECTURE.md against the current code. List any discrepancies or missing topics, then update the doc to resolve them.”**|
|**E. Polish**|**“Improve clarity and concision throughout ARCHITECTURE.md; ensure headings use Title Case and remove redundant phrases.”**|
|**F. Final QA**|**“Run a final validation: confirm all internal links work, all code snippets compile if copied, and no TODOs remain. Summarize fixes applied.”**|

### **Tips for Effective Use**

- **Small batches:** Request one file at a time (Stage C) to stay within context limits.
    
- **Inline corrections:** After any draft, point out factual errors directly – the agent will patch them quickly.
    
- **Persist updates:** If you uncover a new global rule (e.g., diagram format), add it to Agents.md so future runs inherit it.
    

---

### **Ready to Go**

1. **Replace** the {{…}} placeholders in **Agents.md** once.
    
2. **Commit** the file.
    
3. **Kick off** your Codex (or Claude) session with the **Outline** prompt.
    
4. Iterate through the stages; merge docs when satisfied.
    

  

With this split, long‑lived project rules stay in Agents.md, while transient, task‑specific guidance lives in the prompts—keeping both concise and effective.
